# 🌐 Как открыть доступ к приложению с других устройств

Проект запускается на вашем компьютере. Чтобы другие люди могли зайти, нужно:
1. Запустить сервер на `0.0.0.0` (чтобы принимал подключения не только с localhost)
2. Открыть порт в брандмауэре Windows
3. Для доступа из интернета (не только локальной сети) — использовать туннель ngrok

---

## Шаг 1. Запуск сервера

Дважды кликните по файлу:
```
backend\run_public.bat
```

Он:
- активирует виртуальное окружение `.venv`
- установит зависимости
- запустит uvicorn на адресе `0.0.0.0:8000`

Сервер будет доступен:
- с вашего компьютера: `http://localhost:8000`
- с других устройств в вашей Wi-Fi сети: `http://<ВАШ_ИП_В_СЕТИ>:8000`

### Как узнать свой IP в сети
Откройте командную строку и введите:
```
ipconfig
```
Найдите adapter Wi-Fi (например, `Беспроводная сеть`) и строку `IPv4-адрес` — например `192.168.1.15`.  
Тогда другие устройства в той же сети открывают: `http://192.168.1.15:8000`

---

## Шаг 2. Открыть порт в брандмауэре Windows

Если с других устройств не открывается, добавьте правило для порта 8000:

1. Откройте **Панель управления → Система и безопасность → Брандмауэр Защитника Windows → Дополнительные параметры**
2. **Правила для входящих подключений → Создать правило**
3. Выберите **Порт → TCP → 8000 → Разрешить подключение**
4. Укажите имя, например `Bashkar 8000`

---

## Шаг 3. Доступ из интернета (любой человек в мире)

Если хотите, чтобы ссылку можно было отправить человеку из другой сети/города, используйте **ngrok** — бесплатный туннель, не нужны публичный IP и настройка роутера.

### Установка ngrok
1. Зарегистрируйтесь на [ngrok.com](https://ngrok.com/) (можно через GitHub)
2. Скачайте архив ngrok для Windows и распакуйте, например в `C:\ngrok`
3. В личном кабинете скопируйте свой **Authtoken**
4. В командной строке выполните один раз:
   ```powershell
   C:\ngrok\ngrok.exe config add-authtoken ВАШ_ТОКЕН
   ```

### Запуск туннеля
1. Сначала запустите `backend\run_public.bat` (сервер должен быть запущен на 8000)
2. Откройте новую командную строку и выполните:
   ```powershell
   C:\ngrok\ngrok.exe http 8000
   ```
3. ngrok покажет публичную ссылку вида:
   ```
   https://a1b2-c3d4.ngrok-free.app
   ```
4. Эту ссылку можно отправлять любому — она будет открывать ваш сервер.

> ⚠️ Бесплатный ngrok: ссылка меняется после перезапуска, и есть лимиты на трафик/соединения. Для долговременного проекта можно приобрести платный тариг или использовать Cloudflare Tunnel.

## Проверка

После запуска сервера откройте в браузере:
- `http://localhost:8000` — главная страница (дейлик и чат)
- `http://localhost:8000/docs` — документация API
- `http://localhost:8000/health` — проверка работоспособности

Если `health` возвращает `{"status":"ok", ...}` — всё работает, можно делиться ссылкой.

## Структура изменений (для информации)

Файлы, в которые вносились правки для стабильности голосований:
- `backend/app/models/activity.py` — модель `DailyVote` (голосования хранятся в PostgreSQL)

- `backend/app/api/v1.py` — статистика считается из БД, не из памяти (не сбрасывается после перезапуска)
