# bashkar

Монорепозиторий проекта. Три независимых компонента, над каждым работает отдельный человек:

- `backend/` — серверная часть (FastAPI, Python)
- `frontend/` — клиентская часть (React + Vite)
- `bot/` — Telegram-бот (aiogram, Python)

## Структура

```
bashkar/
├── backend/     # FastAPI API
├── frontend/    # React SPA
└── bot/         # Telegram bot
```
